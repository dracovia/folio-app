# Folio v1.6.1 — Transaction amount colors

This is a styling correction to v1.6 (GitHub Sync).

- Expenses appear in burgundy-red with a minus sign.
- Income appears in green with a plus sign.
- Transfers remain neutral.
- Applies to the Transactions page, Dashboard Recent Transactions, Dashboard Coming Up, budget transaction lists, pending payments and Scheduled cards.
- Preserves all financial logic, local storage, budgets, and GitHub Push/Pull.
- Service worker cache version bumped to load the updated stylesheet and app code.

## Update
Back up data before updating (Settings > Download full backup), extract the ZIP, and start as usual. Keep the same browser and local address to retain the same locally stored data. If you see the old styling, close and reopen the installed app or refresh the browser once while connected.
